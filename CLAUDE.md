# Аян: правила для Claude Code

**Начни с `HANDOFF.md`.** Там состояние проекта, план по этапам, список навыков и журнал. Дальше `PRODUCT.md`, `DESIGN.md`, `PLATFORM-STATUS.md`.

Ключевые правила:
- Blender не используется. Всё новое 3D делай в Three.js кодом (процедурные сцены, `AnimationMixer`). Готовые `.glb` в `dist/assets/` остаются как ассеты, `.blend` и `mascot:build` не трогать (см. `HANDOFF.md`, раздел 3).
- Работай в ветке `feat/<имя>`. В `main` не пушить без согласования с владельцем: push в `main` выкладывает сайт на Vercel и запускает миграцию Neon.
- Секреты (`.env*`, ключи Groq, ElevenLabs, `DATABASE_URL`, `BETTER_AUTH_SECRET`) не коммитить и не писать в документы. К рабочей базе Neon не подключаться.
- Перед сдачей задачи: `npm test`, `npm run test:access`, `npm run test:e2e` и команда самой задачи. Сначала падающий тест, потом код.
- Локально: `npm run demo` (порт 4300) или `PORT=4183 node server.mjs`. Node 24.x.
- Тексты для детей на казахском и русском, без длинных тире, только дефис. Спокойное движение, `prefers-reduced-motion`, один шаг на экране.
- Неясно что-то: запиши вопрос в раздел 9 `HANDOFF.md` и переходи к другой задаче. Необратимое (удаление данных, миграция прода, платные сервисы) без ответа владельца не делай.
- После каждой задачи обнови журнал в разделе 10 `HANDOFF.md`.
