# Пакет для Claude Code: модернизация EdTech
Версия 1.0 • 13 ноября 2026 • язык задания: русский.

## Как передать
1. Распакуй ZIP целиком. Передай папку Claude Code в контексте репозитория существующей платформы. В репозитории она может лежать в `brief/EdTech_Claude_Handoff/`.
2. Отправь текст из `START_HERE.txt`. Если используешь Claude Code локально, открой именно репозиторий платформы и укажи путь к распакованной папке.
3. Claude сначала обследует проект, затем исправляет доступ и прогресс, после этого реализует один полный учебный маршрут и расширяет его. Работа с реальными данными и публикация требуют отдельной проверки владельцем.

Для чтения не нужны аккаунты, ключи или интернет. Начни с `PREVIEW.html`: это локальная витрина материалов и иллюстраций. Мастер-промпт — `MASTER_PROMPT.md`. Пять отдельных предложений — `IMPROVEMENTS.md`.

## Что входит
- `design-references/` — оригинальные иллюстрации, схема детского кабинета, дизайн-правила и происхождение материалов.
- `mascot/` — основной светлячок, альтернативы ёжик/сова, требования к Blender и анимациям.
- `video-lessons/` — русские сценарии, раскадровка, субтитры-пример и путь VideoCraft → ElevenLabs → видео.
- `pedagogy/` — шесть двуязычных учебных заготовок, редакционная проверка и схема привязки к программе РК.
- `security-and-ux/` — доступ, прогресс, профиль поддержки и пилот с учителями.
- `implementation/` — этапы, контракты данных, критерии приёмки и официальный справочник источников.
- `MANIFEST.json` — перечень файлов с размерами и SHA-256 для проверки целостности.

## Контекст и границы
Это готовое задание для реализации, а не готовая платформа. Код репозитория, действующие экраны, возраст/класс, учебная программа конкретной школы и настройки авторизации не предоставлены. Внешний вид — предложенное направление, не снимок существующего продукта. По словам пользователя ребёнок и учитель уже отметили непонятный UX и странный маскот; протоколов теста нет. Утверждение об обходе доступа — задача на проверку и исправление, а не доказанный результат аудита.

Рабочая гипотеза для примеров — дети 9–12 лет. «Биология» в детской библиотеке означает тематическую рубрику; официальное название предмета и класс определяет учитель (в том числе «Естествознание»). Коды учебных целей намеренно не выдуманы: публикация блокируется до привязки к выбранной программе.

Основной маскот — светлячок. Ёжик и сова — варианты для короткой проверки; барыс исключён по последнему уточнению пользователя. «Стиль Jaz!» встречался в прежнем ответе ассистента, но ссылка/скриншот не предоставлены; копировать неизвестный бренд не требуется. Предлагается собственный спокойный 3D-стиль.

Есть сценарии и концепты; в пакете нет готовых `.blend`, `.glb`, озвучки ElevenLabs или MP4. Их должен создать Claude с доступными инструментами. Не заявляй, что эти материалы уже готовы. Ключи, данные детей и материалы платных сервисов не включены.
