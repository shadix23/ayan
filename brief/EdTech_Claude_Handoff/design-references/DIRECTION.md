# Визуальное направление
Оригинальный спокойный игровой 3D: тёплый кремовый фон, бирюза, абрикос, тёмный текст, округлые матовые объекты. Светлячок — ведущий, учебный объект — главный. Не копировать чужие бренды, персонажей, интерфейсы или неопределённый «стиль Jaz!».

## Файлы
- `concept-board.png` — оригинальный AI-концепт: светлячок, доли, росток, альтернативы ёжик/сова. Иллюстрации не доказывают учебную корректность: деления дисков проверяются математически в реализации.
- `child-flow.svg` — оригинальная редактируемая схема кабинета с русским текстом; можно открыть в браузере. Это схема, а не финальный UI.
- `GENERATION_PROMPTS.md` — точное задание генерации выбранной иллюстрации.
- `ASSET_RIGHTS.md` — происхождение и правила использования.

## Начальные токены для адаптации к проекту
| Токен | Предложение |
|---|---|
| background | #F8F5ED |
| surface | #FFFFFF |
| text | #17313E |
| primary | #126B68 |
| accent | #F5B57A |
| mint decorative | #A5DED3 |
| danger | #A52D38 + текстовое объяснение |
| radius | 16–24 px |
| spacing | 8, 16, 24, 32 px |

Используй системный sans-serif с поддержкой кириллицы и казахских букв: Ә Ғ Қ Ң Ө Ұ Ү Һ І. Текст задания 18–22 px как начальная гипотеза; заголовки 26–32. Основная кнопка: высота не менее 48 px, зона нажатия удобна на телефоне. Палитра — стартовая: проверь контраст каждой фактической пары текста/фона, не размещай белый мелкий текст на абрикосовом.

## Экран «Мой день»
Верх: язык RU/ҚАЗ, помощь и звук. Заголовок «Сегодня исследуем доли». Одна большая карточка «Продолжить урок», внутри три шага, прогноз длительности без таймера. Ниже две вторичные ссылки «Игры» и «Видео». Светлячок рядом с карточкой, без всплывающего окна поверх задания. Учительский кабинет имеет собственную навигацию.

## Состояния для реализации
Загрузка; нет назначений; нет видео по фильтру; ошибка сети; ответ не сохранён; сохранено; правильный/неправильный ответ с объяснением; частичный прогресс; версия урока снята с публикации; 3D не поддерживается; звук выключен; reduced motion. Не кодируй статус только цветом. Не открывай ребёнку служебные сообщения сервера.
