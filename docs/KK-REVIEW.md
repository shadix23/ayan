# Казахские строки на проверку носителем языка

Собирается командой `node scripts/kk-review.cjs`. Интерфейс кабинета, урок ребёнка, «Мой день», игра «Собери долю», видео и субтитры M01, настройки, отчёт родителю, вход, страница о данных, шаблоны уроков. Перевод сделан без носителя языка: проверьте естественность и терминологию (особенно математические термины).

Как отметить правку: исправьте текст в колонке «Каз» прямо в этом файле, разработчик перенесёт его в код.
