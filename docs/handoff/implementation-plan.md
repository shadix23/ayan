# План реализации

Основа: текущая архитектура (один `server.mjs`, SQLite/Postgres, статический `dist/`). Новых фреймворков не вводим. Каждый шаг маленький и с проверкой.

## Этап 1: доступ и корректность (делается сейчас)

1. **Версии урока.** Новая таблица `ayan_lesson_versions` (неизменяемые копии). Публикация создаёт версию N+1, `ayan_lessons` указывает на текущую. Существующие уроки переносятся как версия 1 при старте.
2. **Попытки и ответы.** Таблицы `ayan_attempts` и `ayan_submissions`. Ключ ответа: ученик + attemptId + taskId + submissionId. Повтор того же ответа возвращает сохранённый результат, другой текст под тем же ключом отклоняется (409). Оценка по ключу той версии, в которой начата попытка. Завершение атомарно (`UPDATE ... WHERE state <> 'completed'`), поздний ответ его не откатывает. Пустой ответ - 400, а не «неверно».
3. **События.** Шаги, подсказки и пауза получают `lesson_version` и `attempt`; номер шага проверяется. Ответ через старый `/api/lesson/event` больше не принимается.
4. **Клиент урока.** Состояния `editing → submitting → evaluated` и `save_failed → retry` с тем же submissionId. При неизвестном исходе сначала запрос сохранённой попытки. «Урок завершён» только после подтверждения сервером.
5. **Наблюдения по ученику.** Каждое наблюдение получает studentId и версию урока; кабинет показывает только наблюдения выбранного ученика.
6. **Отзыв доступа.** `POST /api/children/revoke`: удаляет сессии ребёнка, приглашения и ссылки родителя. Кнопка в панели учителя.
7. **Тесты.** `tests/access-matrix.mjs`: отрицательные проверки из `SECURITY.md`, повтор, конфликт, пустой ответ, две вкладки, поздний ответ после завершения, отзыв.

Миграция: только добавление таблиц и колонок (`ALTER TABLE ... ADD COLUMN` в try/catch для SQLite). Старые данные не удаляются. Откат: вернуть предыдущий `server.mjs`; новые таблицы старым кодом игнорируются, колонки в `ayan_events` допускают NULL.

Не входит в этап 1 (известное ограничение): серверная проверка результатов игр (A4). Игры сейчас целиком на клиенте; проверка будет вместе с новыми играми этапа 3.

## Этап 2: понятный маршрут

«Мой день» → урок → объяснение → практика → результат → следующий шаг; вкладки «Игры» и «Видео»; профиль поддержки (язык, крупный текст, субтитры, движение, звук); состояния загрузки, ошибок и пустые.

## Этап 3: полный урок M01

Игра «Собери долю» на Three.js и равноценный 2D-вариант с той же оценкой на сервере; видео M01 (ElevenLabs + рендер, перед этим переключение модели на Fable 5.2 по просьбе пользователя); субтитры; результат в отчёте.

## Этапы 4-5

Шесть уроков RU/KK (статус draft до проверки педагогом и привязки к программе), игры «Помоги ростку» и «Маршрут светлячка», три видео; пакет доверия и протокол пилота (значения заполняет владелец).
