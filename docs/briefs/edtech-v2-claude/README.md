# EdTech V2.1 · пакет для Claude Code

Полное ТЗ, реальные примеры с Dribbble, выбранные пользователем картинки, оригинальные макеты и требования к реализации. Дата: 13 ноября 2026. Язык документов — русский. Это пакет для продолжения существующего проекта, а не готовое приложение.

## Быстрый старт

1. Распакуй ZIP. Сохрани папку `edtech-v2-claude` рядом с текущим проектом либо в его `docs/briefs/`. Не заменяй ею код проекта и не перезаписывай существующий `CLAUDE.md`.
2. Открой тот же проект и тот же чат Claude Code, где выполняется первое ТЗ.
3. Прикрепи папку или укажи её фактический локальный путь и отправь текст из `START_HERE.txt`.
4. Claude сначала сверяет текущее состояние, затем дополняет проект и проверяет всё на localhost. Деплоя, push и платных API в этом этапе нет.

Если Claude не может читать ZIP, распакуй его и дай доступ к папке. Отдельно попроси открыть сами PNG; чтения только Markdown недостаточно для визуального соответствия. Название EdTech и имя Тумо в новых макетах рабочие: текущий бренд проекта сохраняется.

## Как понимать визуальные материалы

`design-references/dribbble/01-alagalms.png` — именно тот AlagaLMS «Hello, Abi», который пользователь показывал. Остальные пять примеров с Dribbble дополняют подборку. Часть работ показывают композицию или компонент, а не точный функциональный аналог всего модуля.

Семь изображений в `provided/` — сами видимые картинки, аккуратно вырезанные из последних вложений пользователя. Ранние семь картинок извлечены без рамки приложения. Два новых кадра Duolingo English Test приложены целиком по запросу пользователя в отдельной папке duolingo/. Эти файлы не называются скачанными оригиналами: в manifest сохранено их происхождение. Первая картинка AlagaLMS присутствует и в Dribbble, и в выбранной пользователем подборке; это не две разные работы.

`ui-mockups/` — согласованный визуальный ориентир нового интерфейса, нарисованный специально для этого пакета. Это растровые PNG и векторные SVG, не сгенерированные фотографии и не рабочие экраны приложения. 3D-сцена показана как визуальный концепт с перспективой: настоящую Three.js-сцену и GLB-маскота Claude реализует в текущем проекте.

Внешние картинки служат референсами: атрибуция не означает передачу прав на включение чужих иллюстраций и брендов в продукт. Собственные макеты задают единый стиль, который нужно реализовать своими компонентами.

## Границы готовности

ZIP готов к передаче Claude. Приложение в этой задаче не изменялось, не запускалось и не деплоилось. Видео, 3D-модель и реальные провайдеры не выдаются за созданные ассеты. В пакете есть требования и раскадровка, а их реализация — следующий этап Claude.

Доступная история содержит полное ТЗ V2, но не полный исходный текст V1 или репозиторий проекта. Поэтому пакет прямо требует сверки с тем, что Claude уже делает. Шесть уроков и казахские варианты требуют педагогической/языковой проверки. Источники для UDL и WCAG указаны в UDL_ACCESSIBILITY.md; наличие требований не является сертификацией приложения или обещанием учебного результата.

## Строго локально

Никаких Vercel/Netlify/preview deployments, git push, production-БД и платных API. Даже существующий API-ключ не активирует провайдер. ElevenLabs и VideoCraft — только отключённые контракты/локальные mocks. Приложение должно загружать локальные ассеты и работать с локальным backend. Проверки безопасности выполняются на синтетических данных.


## Что добавлено в V2.1

- Полное дополнение UDL с разными способами ответа, переносом понятия на новую фигуру и управляемыми подсказками.
- Конструктор одного доступного шаблона RU/KK с предпросмотром ученика и закреплением версий.
- Переход из отчёта к следующему назначению, школьный пилот и локальная тестовая подписка.
- План на три дня, сценарий защиты и дополнительные критерии приёмки.
- Требования ревью текущего светлячка в проекте и создания новой модели через Blender с .blend, GLB, клипами и статичным fallback.
- Новый оригинальный PNG-концепт светлячка. Изображение создано встроенной генерацией изображений для этого пакета. Оно служит визуальным заданием для Blender.
- Два дополнительных UI-референса Duolingo English Test и бирюзово-медовая палитра. PNG/SVG-макеты перекрашены, размещение прежнего робота нужно использовать для нового светлячка.

Оба дополнения включены непосредственно в MASTER_PROMPT.md как разделы 17–18, а также доступны отдельными файлами requirements/. Текущая модель проекта в этой задаче не была доступна для просмотра. Её реальное ревью включено в работу Claude.
