# Проверка пакета

Дата: 13 ноября 2026. Проверялся архив ТЗ и визуальных материалов, не приложение пользователя.

- PASS: 6 PNG реально скачанных работ Dribbble; авторы, публикации и CDN указаны в SOURCES.md.
- PASS: 7 отдельных картинок из пользовательских вложений; рамка ChatGPT и боковые чаты исключены.
- PASS: 13 оригинальных PNG-макетов и 13 соответствующих SVG-исходников; размеры совпадают с manifest.
- PASS: 32 PNG, включая 3 обзорных листа, открываются и проходят проверку целостности.
- PASS: все локальные ссылки галереи и Markdown ведут к существующим файлам.
- PASS: исходное ТЗ сохранено с разделами 0–16; MASTER_PROMPT добавляет UDL для всех детей и строгие local-only ограничения.
- PASS: документы включают реализацию, события, серверные права, шесть ru/kk уроков, медиа-адаптеры, доступность и будущую приёмку.
- PASS: в MASTER_PROMPT включены разделы 17–18 с UDL-улучшениями, конструктором, тестовым пилотом, трёхдневным планом, новой Blender-моделью и палитрой.
- PASS: добавлены два исходных снимка пользователя Duolingo English Test и один оригинальный концепт светлячка с промптом.
- PASS: изображения визуально просмотрены; исправлено соответствие изображений долей подписям 1/2, 1/4, 3/4.
- PASS: семь прежних картинок сохранены без рамки ChatGPT. Два новых снимка браузера включены по прямому запросу пользователя. История чатов и исполняемый код приложения в пакет не включены.

Оригинальные UI-макеты созданы как векторные композиции с PNG-экспортом. Новый концепт светлячка создан встроенной генерацией изображений. Новая модель .blend/GLB должна быть реализована Claude. Прежний робот в макетах показывает только размещение персонажа.

Не проверялось: приложение, репозиторий, backend, реальные роли, обучение детей, соответствие программе, качество будущих RU/KK уроков. Эти проверки должен выполнить Claude в существующем проекте по ACCEPTANCE_TESTS.md. VideoCraft и ElevenLabs не вызывались; видеофайл и GLB-модель не входят в пакет.

FILE_MANIFEST.json перечисляет SHA-256 всех файлов кроме самого себя. После упаковки проверяются CRC каждого ZIP-элемента и совпадение содержимого с манифестом.
