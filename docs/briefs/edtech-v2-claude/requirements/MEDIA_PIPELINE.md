# Видеоуроки — локальный pipeline и демонстрационный сценарий

Продолжать существующий проект. Не деплоить, не выполнять push, не запускать платные API и не публиковать AI-материалы. Ни наличие ключа, ни уже установленная интеграция не разрешают запросы ElevenLabs или другой платный сервис. В этом этапе Claude должен создать один локальный демонстрационный урок; настоящий видеофайл не входит в данный пакет ТЗ.

## 1. Режим исполнения и адаптеры

По умолчанию использовать только локальные fixtures: готовый разрешённый аудиофайл либо тихую демонстрацию без голоса с субтитрами и расшифровкой. Подпись «Демо: локальная дорожка» обязательна, если настоящей озвучки нет. Не маскировать сигнал/тишину под речь ElevenLabs. Для 3D-сцен использовать существующие Three.js/Blender-инструменты без скачивания платных ассетов.

Предусмотреть интерфейсы `SpeechProvider`, `VideoRenderer`, `CaptionSource` по паттернам проекта. Активный speech provider — `localFixture`; будущий `elevenLabs` отключён и не исполняет сетевых запросов. Защитить локальный режим проверкой на стороне сервера; одного скрытого переключателя в UI недостаточно. Не помещать ключи в клиентский код. В тесте перехватить исходящий HTTP и доказать отсутствие платных вызовов, даже если переменные ключей заданы.

VideoCraft — желаемый инструмент, а не подтверждённая зависимость. Сначала проверить, существует ли в проекте соответствующий skill/адаптер и какие локальные возможности он реально предоставляет. Не выдумывать API или название команды. При отсутствии продолжить локальным рендером существующими средствами, записать ограничение и оставить отключённую точку интеграции. Не устанавливать новый платный сервис ради MVP.

## 2. Артефакты одного урока

Один Lesson ID и версия связывают видео, объяснение, Fraction World и мини-тест. У урока две локализации `ru` и `kk` с отдельными дорожками/субтитрами; материал проверяет учитель, казахский текст дополнительно проверяет компетентный носитель. Учебная цель: определить 1/4 как одну из четырёх равных частей. Официальное соответствие программе Казахстана пока пометить «требует проверки».

Хранить относительные пути к видео, постеру, аудио, WebVTT, расшифровке и сценарию; `lessonVersion`, `language`, `duration`, `reviewStatus`, `reviewedBy`, `reviewedAt`, происхождение и лицензию ассетов. Черновик нельзя показывать как одобренный учителем. Версия критериев мини-теста фиксируется вместе с попыткой.

## 3. Раскадровка: «Одна четверть», 75 секунд

Темп спокойный; камера неподвижна, маскот занимает небольшую область. Четыре сектора имеют одинаковую площадь. Выбранная часть выделяется цветом и контуром. Никаких конфетти, моргания, обязательного звука или autoplay. Тексты ниже — рабочий черновик для педагогической и языковой проверки.

| Время | Кадр | Реплика RU | Реплика KK |
|---|---|---|---|
| 00–10 | Целая пицца; подпись «Целое» | Это целая пицца. Посмотрим, что такое одна четверть. | Бұл — бүтін пицца. Төрттен бір бөлік деген не екенін көрейік. |
| 10–25 | Два диаметра делят круг на четыре сектора | Разделим пиццу на четыре равные части. Все части одинакового размера. | Пиццаны төрт тең бөлікке бөлеміз. Барлық бөліктердің өлшемі бірдей. |
| 25–40 | Один сектор выделен; подпись «1 из 4» | Выберем одну из четырёх равных частей. Это одна четверть. | Төрт тең бөліктің біреуін таңдаймыз. Бұл — төрттен бір бөлік. |
| 40–55 | Запись 1/4, по очереди спокойная подсветка цифр | Запишем: одна четвёртая. Четыре показывает число равных частей. Один — сколько частей мы выбрали. | Оны бір бөлінген төрт деп жазамыз. Төрт саны тең бөліктердің санын көрсетеді. Бір саны таңдалған бөліктердің санын көрсетеді. |
| 55–65 | Другая фигура из четырёх равных прямоугольников; один выделен | У другой фигуры тоже можно выбрать одну четверть. Важно, чтобы части были равными. | Басқа пішіннің де төрттен бір бөлігін таңдауға болады. Бөліктердің тең болуы маңызды. |
| 65–75 | Крупные кнопки «Повторить» и «Попробовать» | Теперь выбери одну из четырёх равных частей сам. Можно повторить объяснение. | Енді төрт тең бөліктің біреуін өзің таңда. Түсіндірмені қайта көруге болады. |

Последовательность реплик составляет полную расшифровку. При записи речи подогнать длительности под реальный темп, а не растягивать аудио до таймкодов любой ценой. Генерировать отдельные короткие WebVTT cues по фразам; не размещать всю реплику на экране сразу. Казахская математическая терминология требует проверки до снятия статуса черновика.

## 4. Плеер и приёмка

Пауза, play, скорость 0.75/1/1.25, повтор текущего фрагмента, субтитры, расшифровка и переход в 2D/3D доступны с клавиатуры. Субтитры не закрывают объект. Сохранение позиции работает по Lesson ID, версии и языку, включая перезагрузку; смена формата не завершает урок автоматически. При смене языка переходить к соответствующему смысловому сегменту либо объяснённо начинать его сначала — не переносить секунды вслепую между разными дорожками.

Мини-тест содержит 3 задания: узнать 1/4 на круге, отличить равные части от неравных, перенести понятие на прямоугольник. Есть повтор и подсказка; ошибки доставки ответа не считаются неверным решением. Результаты поступают в ту же event model, что и игра.

Проверить локальный путь к медиа, MIME, отсутствие сетевых вызовов платных сервисов, ручной запуск, pause/resume после reload, синхронность субтитров с речью, текстовую альтернативу, доступность контролов, оба языка и отсутствие детских данных в материалах. При недоступном видео показать расшифровку и практику с понятным сообщением. Готовность требует просмотра учителем всего ролика, проверки математики, языка, прав на материалы и качества синхронизации.
