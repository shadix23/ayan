# Новые приоритеты V2.1

Открой design-references/duolingo/01-layout-original.png и 02-illustration-original.png. Это два новых кадра пользователя. Их сильные стороны — воздух, простая иерархия, крупные кнопки, округлые формы и единый акцент. Для персонажа открой design-references/mascot-concept/01-firefly-blender-reference.png. Это новый оригинальный пример для Blender. Точные требования описаны в requirements/MASCOT_REDESIGN_AND_UI.md.

Новая палитра внесена в токены и 13 UI-макетов. Прежний робот внутри этих композиций показывает место персонажа. При реализации замени его новым светлячком. Новые концепт и требования имеют приоритет над старой формой робота.

# Как читать изображения

Три отдельные группы: `design-references/dribbble/` — настоящие скачанные примеры с Dribbble; `design-references/provided/` — семь картинок, извлечённых из предоставленных пользователем скриншотов без интерфейса ChatGPT; `ui-mockups/` — новые оригинальные макеты для проекта. Исходные полноэкранные скриншоты пользователя в пакет не включены.

Происхождение и авторы Dribbble перечислены в `design-references/dribbble/SOURCES.md`. Не представлять чужие работы как собственные и не считать их ассетами продукта. У извлечённых картинок исходная детализация ограничена отображённой пользователю версией; это не оригинальные скачивания с сайтов. `provided/manifest.json` фиксирует происхождение.
