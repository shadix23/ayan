# Казахские строки V2.1 на проверку носителем языка

Собирается командой `node scripts/kk-review-v2.cjs`. Кабинет ученика и учителя V2.1, маршрут урока, Fraction World, видео, шесть уроков (темы, цели, объяснения, задания, подсказки), обратная связь. Перевод сделан без носителя языка: проверьте естественность и школьную терминологию, особенно дроби (ширек, төрттен бір), биологию (жасуша, вакуоль) и информатику (алгоритм, шарт).
