# V2.1: ход реализации

Источник требований: `docs/briefs/edtech-v2-claude/` (пакет V2.1 от 13.11.2026). Режим работы: только локально. Деплоя, push, preview, платных API и production-БД в этой итерации не было. Ключи в окружении не используются: платные провайдеры включаются только переменной `AYAN_PAID_PROVIDERS=enabled`.

## Как запустить

```bash
npm run demo
```

Откройте http://127.0.0.1:4300/demo и выберите синтетический аккаунт (учитель A/B, администратор A/B, ученики 01-03 и B1, родитель ученика 01). Демо-режим работает только на отдельной локальной базе `.data/demo.sqlite` и отказывается стартовать рядом с Postgres или на Vercel. Кнопка «Сбросить демо-данные» создаёт их заново.

Обычный режим (`npm start`, порт 4183): вход учителя `/teacher/login`, ученика по коду `/child/login`. Прежние кабинеты сохранены: `/teacher/classic`, `/child/classic`, клиентское демо `/demo/teacher`, `/demo/child`.

## Готово (реализовано и подключено к серверу)

- **Сервер:** `learning.mjs` (организации, план, назначения, попытки V2, события, помощь, отчёт, рекомендации, заметки, экспорт и удаление, конструктор, preview, пилот), `support.mjs` (полный профиль поддержки, слияние по полям, позиция видео), `media-adapters.mjs` (localFixture активен, ElevenLabs и VideoCraft отключены), `demo-seed.mjs`. Маршруты в `server.mjs` (`/api/v2/*`, `/api/demo/*`).
- **Ядро заданий:** `dist/v2/lesson-core.js` - один evaluator на сервере и в браузере; дроби оцениваются по площади (точная арифметика), три способа ответа меряют одну цель; choice / match / order для других уроков.
- **Уроки:** `dist/v2/lessons.js` - шесть уникальных lessonId, у каждого ru и kk, gradeProposal, objectiveDraft, successCriteria, materials, 5 этапов, 5 заданий + проверка, `curriculumVerification: pending_teacher_review`, `curriculumSource: null`.
- **Кабинет ученика:** `dist/v2/child.mjs`, `lesson.mjs`, `fraction-world.mjs`, `tasks.mjs`, `video.mjs`, `mascot.mjs`, `figures.mjs`, `ui.mjs`, `tokens.css`. Outbox на устройстве привязан к пользователю; этап и черновики сохраняются с ревизией.
- **Кабинет учителя и администратора:** `dist/v2/adult.mjs` - ученики и приглашения, назначение (группой - в пилоте), сводный и подробный отчёт, «Назначить следующий пример», профиль поддержки, конструктор с preview глазами ученика, библиотека, тестовый пилот, обзор организации.
- **Маскот:** `assets-src/firefly_build.py` → `assets-src/firefly.blend`, `dist/assets/mascot/firefly.glb` (385 КБ, 16 784 треуг.), 7 PNG. Подробно: `docs/MASCOT_REVIEW.md`.
- **Независимое ревью Codex** (`docs/CODEX_REVIEW_V2.md`): найдено 12 подтверждённых проблем и 3 подозрения, все исправлены и покрыты тестами. Среди них падение сервера от одного кривого JSON, поломка 5 уроков из 6 после первого верного ответа и риск стереть локальную базу демо-посевом.
- **Палитра:** `dist/v2/tokens.css`; прежние страницы переведены на токены через `dist/v2/bridge.css`; новый логотип `dist/assets/ayan-mark.svg` (прежний сохранён в `assets-src/ayan-mark-v1.svg`).
- **Видео M01 0.2.0:** `dist/media/M01/0.2.0/` - `lesson.mp4` (3,7 МБ, плавные наезды и панорамы до 1,15×, параллакс трёх слоёв) и `lesson.calm.mp4` (2,5 МБ, неподвижная камера). Озвучка, тайминг, субтитры и расшифровка те же, что в 0.1.0; новых платных запросов не было. Плеер сам берёт спокойную версию при тихом режиме, минимальном движении или системной настройке. Сборка: `video/lessons/m01/build-notes.md`.
- **ИИ-помощник** прежнего кабинета не вызывает внешние API без `AYAN_PAID_PROVIDERS=enabled`.

## Mock-зоны и ограничения

- Оплата: только локальный mock checkout (`mode: local_mock`), исходы success / fail / cancel / pending задаются явно; реквизиты карт не собираются, деньги не списываются. Цена и срок реального тарифа не согласованы.
- Озвучка: локальная запись M01 (RU) из прошлого этапа; казахской озвучки нет, это честно показано. Голос маскота - только голос устройства (`localService`), по умолчанию выключен. ElevenLabs и VideoCraft отключены; VideoCraft в проекте нет.
- Видео M01 0.2.0 никто из педагогов не смотрел: статус `review`, в интерфейсе метка «видео ждёт проверки учителем». Ударения в озвучке на слух не проверялись.
- Содержание шести уроков, цели программы и все казахские тексты требуют проверки педагогом и носителем языка. Пока стоит метка «Демо · цель программы требует проверки».
- Администратор видит только сводку организации; детали ученика - только у назначенного учителя.
- Родитель видит отчёт по ссылке учителя (без отдельного аккаунта) и не меняет настройки ребёнка.
- Скринридер вживую не прогонялся; казахский длинный текст на 320 px проверен выборочно.
- Прежний кабинет `/teacher/classic` и его ИИ-конструктор оставлены без изменений; назначения V2.1 там не отображаются.
